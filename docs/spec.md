# Zree spec

Behaviour that must be **identical on macOS and Android**. Visual design is up to each platform.
The source of truth for the implementation is `core/` (Rust). If this document and the code disagree,
either fix the code or fix this document — do not let them drift.

## 1. Vault

- A vault is one folder. Everything inside it is notes and resources.
- Scanned: `**.md` (recursive), excluding
  - directories beginning with `.` (`.git`, `.obsidian`, `.trash`)
  - `assets/` (attachments only)
- Note id = path relative to the vault, `/` separated. e.g. `ワンネス メンタリング 230502.md`
- Title = file name without the extension
- Order: newest modified first, ties broken by title ascending

## 2. File operations

| Operation | Rule |
|---|---|
| Create | without a title: `Untitled yyMMdd-HHmm` (local time) |
| Name collision | `title 2.md`, `title 3.md`, … (never overwrite) |
| Rename | same directory only; error if the target exists |
| Delete | moved to `.trash/`, not removed (`title 2.md` on collision) |
| Title sanitising | `/ \ : NUL CR LF TAB` → `-`; trim leading/trailing spaces and dots; collapse `..` to `.`; max 100 chars; empty result is an error |

**Overwrite guard**: on write, if the current mtime differs from the mtime observed when the note was
loaded, return `Conflict`. The UI reports "changed on disk" and never overwrites silently.

## 3. Tags

Inline tags only; no frontmatter.

- `#` must be at the start of a line or directly after whitespace
- The body ends at whitespace, `#`, or a terminator (`、。，．！？「」『』（）【】・…—–` plus ASCII
  `, . ! ? " ' ( ) [ ] { } \` | \ / ; : * _ ~ = + ^ $ % & @`)
- **Excluded**:
  - `#` followed by whitespace → heading, not a tag
  - 3–8 characters, all hex digits → colour literal (`#fff`, `#1a2b3c`)
  - anything inside fenced code blocks or inline code spans
- Case is preserved. Duplicates collapse to the first occurrence.
- Filtering with several tags is AND.

## 4. Search

Japanese is written without spaces, so nothing is tokenised.

1. Normalise both query and body with **NFKC + lowercase** (width and case collapse)
2. Split the query on whitespace; **every term** must appear in the title or the body (AND)
3. Score: title match +100 (exact title +500), body match +10 + occurrences (capped at 10)
4. Snippet: 20 characters before and 40 after the first match, newlines flattened
5. An empty query returns everything, newest first

The index is held fully in memory and rebuilt lazily after mutations (fine up to tens of thousands of notes).

## 5. Markdown

Supported blocks: headings (`#`–`######`, space required after the hashes), bullet lists
(`-` `*` `+`, 2 spaces per indent level), ordered lists, checkboxes (`[ ]` `[x]`), blockquotes (`> `),
fenced code, images, paragraphs.
Supported inline: `**bold**`, `*italic*`, `~~strike~~`, `` `code` ``, `[text](url)`, `![alt](src)`.

The core **does not generate HTML**. It returns a token stream that each UI renders natively.

### Images

After migration, standard syntax only:

```
![](assets/2025-05-16-101726.png)
```

- Attachments live in `assets/`
- Names are `YYYY-MM-DD-HHMMSS.ext`, generated by the app on paste
- `![[file.png]]` is still understood for backward compatibility and is dropped once migration is done

### Note links

Standard syntax only. `[[wikilink]]` is not supported.

Resolution rules (`resolve_link`):

1. `#heading` alone → not a link
2. `http://`, `https://`, `mailto:`, `zree:` → external
3. drop the anchor (`#…`) and query (`?…`)
4. percent-decode (`%20`, `%E3%83%A1`, …)
5. a leading `/` is relative to the vault root, anything else to the current note's directory
6. append `.md` when there is no extension
7. success only if the file exists; paths escaping the vault through `..` are rejected

Clicking a link navigates to that note (the UI intercepts it as `zree://note?id=<id>`).

## 6. Git

- The vault itself is the repository (`.git` next to the notes)
- **Sync = commit (everything) → pull → push**
- Commit: a clean tree is a no-op, not an error
- Pull:
  - only behind (behind > 0, ahead = 0) → fast-forward
  - diverged → real merge; on conflict **stop without pushing** and return the conflicted paths
- Conflict resolution: `mine / theirs / both` (both = ours + newline + theirs). A merge commit finalises it
- Pull on launch runs only when the worktree is clean, nothing is merging, there are no conflicts and behind > 0
- Auth: HTTPS + PAT (macOS Keychain) or ssh-agent

## 7. Errors

User-facing strings are Japanese. Nothing is swallowed: save and sync failures are always surfaced.
`Conflict` means "a human must decide" — it is never auto-resolved.
