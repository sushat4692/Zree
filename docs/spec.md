# Zree 仕様

macOS と Android で**挙動を一致させる**必要があるものの定義。UIの見た目は各OSに任せる。
実装の正は `core/`（Rust）。この文書と実装が食い違ったら実装を直すか、この文書を直す。

## 1. Vault

- Vault = 1フォルダ。その中身がすべてノートとリソース
- 走査対象: `**.md`（再帰）。ただし以下は除外
  - `.` で始まるディレクトリ（`.git`, `.obsidian`, `.trash`）
  - `assets/`（添付ファイル専用）
- ノートID = Vaultからの相対パス（`/` 区切り）。例: `ワンネス メンタリング 230502.md`
- タイトル = 拡張子を除いたファイル名
- 並び順: 更新日時の降順、同時刻ならタイトル昇順

## 2. ファイル操作

| 操作 | 規則 |
|---|---|
| 新規 | タイトル未指定なら `Untitled yyMMdd-HHmm`（ローカル時刻） |
| 名前衝突 | `タイトル 2.md`, `タイトル 3.md` …（上書きしない） |
| リネーム | 同一ディレクトリ内のみ。既存名と衝突したらエラー |
| 削除 | 実削除せず `.trash/` へ移動（`タイトル 2.md` で衝突回避） |
| タイトル正規化 | `/ \ : NUL 改行 タブ` → `-`、前後の空白と `.` を除去、連続する `..` を `.` に畳む、100文字上限、空になったらエラー |

**上書きガード**: 書き込み時、読み込み時のmtimeと現在のmtimeが違えば `Conflict` エラー。UIは「外部で更新されています」を出し、勝手に上書きしない。

## 3. タグ

インラインタグのみ（frontmatterは使わない）。

- `#` が行頭または空白の直後にあるもの
- 本文は空白・`#`・区切り記号（`、。，．！？「」『』（）【】・…—–` と ASCII の `, . ! ? " ' ( ) [ ] { } < > \` | \ / ; : * _ ~ = + ^ $ % & @`）で終わる
- **除外**:
  - `#` の直後が空白 → 見出し（タグではない）
  - 長さ3〜8で全て16進文字 → 色コード（`#fff`, `#1a2b3c`）
  - フェンスコードブロック内、インラインコード内
- 大文字小文字は保持。重複は初出順で1つに畳む
- 絞り込みは全タグAND

## 4. 検索

日本語は空白で区切らないため、トークン化しない。

1. クエリと本文を **NFKC正規化 + 小文字化**（全角/半角、大小文字を同一視）
2. 空白でクエリを分割し、**すべての語**がタイトルか本文に含まれること（AND）
3. スコア: タイトル一致 +100（完全一致 +500）、本文一致 +10 + 出現回数（上限10）
4. スニペット: 最初の一致位置の前20文字・後40文字、改行は空白に
5. 空クエリは全件（更新日時降順）を返す

インデックスはメモリ上に全件展開。変更後は遅延再構築（1万ノート程度までは実用）。

## 5. Markdown

対応するブロック: 見出し（`#`〜`######`、`#`の後に空白必須）、箇条書き（`-` `*` `+`、インデントは2スペース単位）、番号付き、チェックボックス（`[ ]` `[x]`）、引用（`> `）、フェンスコード、画像、段落。
インライン: `**bold**`、`*italic*`、`~~strike~~`、`` `code` ``、`[text](url)`、`![alt](src)`。

コアは **HTMLを生成しない**。UIが描画できるトークン列を返す。

### 画像

移行後は標準記法のみ:

```
![](assets/2025-05-16-101726.png)
```

- 添付は `assets/` に置く
- ファイル名は `YYYY-MM-DD-HHMMSS.ext`（貼り付け時にアプリが自動命名）
- 互換のため `![[ファイル名.png]]` も当面は解釈する（移行完了後に削除）

### ノート間リンク

標準記法のみ。`[[wikilink]]` は使わない。

解決規則（`resolve_link`）:

1. `#見出し` のみ → リンクではない
2. `http://` `https://` `mailto:` `zree:` → 外部リンク
3. `#` 以降（アンカー）と `?` 以降（クエリ）を捨てる
4. パーセントデコードする（`%20`、`%E3%83%A1` など）
5. `/` 始まりはVaultルート基準、それ以外は現在のノートのディレクトリ基準
6. 拡張子が無ければ `.md` を補う
7. 実在するファイルのみ解決成功。`..` でVault外に出るパスは拒否

リンクはクリックでそのノートに遷移する（`zree://note?id=<id>` としてUIが横取り）。

## 6. Git

- Vault自身がリポジトリ（`.git` を同居）
- **同期 = commit（全変更）→ pull → push**
- commit: 差分が無ければ何もしない
- pull:
  - 遅れのみ（behind>0, ahead=0）→ fast-forward
  - 分岐 → 実マージ。衝突したら**pushせず停止**し、衝突ファイル一覧を返す
- 衝突解決: `自分 / 相手 / 両方`（両方は自文＋改行＋相手文）。全解決後にマージコミット
- 起動時の自動pull: **変更なし・衝突なし・マージ中でない・behind>0** のときだけ実行
- 認証: HTTPS + PAT（キーチェーン保存）、または ssh-agent

## 7. エラー

UIに出す文言は日本語。握りつぶさない（保存失敗・同期失敗は必ず表示）。
`Conflict` はユーザーの判断が必要な状態として扱い、自動解決しない。
